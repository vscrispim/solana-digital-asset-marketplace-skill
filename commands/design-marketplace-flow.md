# Command: Design Marketplace Flow

Use this when the founder has a marketplace idea but no clear end-to-end buyer journey.

Inputs:

- asset category;
- buyer persona;
- creator persona;
- checkout preference;
- desired Solana role;
- delivery requirements.

Output:

- buyer journey;
- creator journey;
- off-chain architecture;
- Solana proof points;
- manual MVP steps;
- risks and next actions.
