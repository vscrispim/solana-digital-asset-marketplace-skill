# Metrics and Funnel

## Goal

Define metrics that prove marketplace demand instead of vanity launch activity.

## Supply metrics

- creators contacted;
- creator replies;
- interviews booked;
- creators approved;
- assets submitted;
- assets published;
- assets with complete license data.

## Demand metrics

- landing visits;
- asset page views;
- preview interactions;
- license tier clicks;
- checkout starts;
- completed purchases/tests;
- download completions;
- repeat visits;
- support requests.

## Trust metrics

- creator response time;
- useful comments/reviews;
- refund/dispute rate;
- download failure rate;
- license questions before purchase;
- license questions after purchase.

## First validation targets

A good early target:

- 50 creators researched;
- 20 personalized messages;
- 5 interviews;
- 3 creators interested;
- 5 assets ready for concierge listing;
- 50 qualified visitors;
- 5 checkout intent clicks;
- 1 real or simulated purchase.

## Output format

Return a 2-week validation dashboard with events, targets, and what decision each metric supports.

## Safety boundary

This module is not legal, financial, or security advice. It helps structure founder decisions and prepare better questions for counsel, engineers, and operators.
